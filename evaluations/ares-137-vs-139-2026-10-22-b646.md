# Ares 1.3.137 vs 1.3.139: matched hue comparison

Date: 2026-10-22

**Result: exclude 1.3.139 from API publication.** On this fixed development cohort, increasing training hue gain from 0.015 to 0.5 did not improve fast observation coverage and increased false positives in a fixed session.

This evaluates the [audited 139 training experiment](../trainings/ares-v1.3.139-2026-10-22-b645.md). The selected epochs differ: 137 uses epoch 1; 139 uses epoch 5.
