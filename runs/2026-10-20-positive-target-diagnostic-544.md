# Positive soft-target diagnosis and next trial — 2026-10-20, batch 544／545

本輪完成一次只讀的 TRAIN 診斷，並為下一個單變量候選完成 CPU loss 測試。**沒有新增訓練完成的權重，也未證明高速漏判改善。**

## 為什麼做這次診斷

[上一輪 v1.3.110](2026-10-20-native-positive-training-539.md) 已完成 30 epochs、固定回歸及本機 API 上架；高速組仍為 TP／FP／FN 45／2／7。本次先檢查正例配對的分類目標分數，而非調低 confidence 或重新挑選舊測試結果。

更正早期解讀：首次預檢更新了 8 組偏置，但最後選中的模型實際已有 34 組 P2 參數改變；訓練並非永久限制為只更新偏置。

## 固定診斷範圍

使用已在 batch 537 封存、屬於同一既有 TRAIN 拍攝場景的 12 張原始正例、23 個 LLM 框；沒有使用 VAL、TEST 或保留的最終驗收來源。標註來源仍為 LLM，human_confirmed=false、review_status=pending。

比較原始 seed 42 初始化權重與實際 v1.3.110。每份權重跑 3 批、每批 4 張、640 letterbox、無增強，共 **2 次權重載入、6 次直接模型前向、6 次 criterion 呼叫**。沒有 backward、optimizer 更新、epoch、checkpoint 儲存或 API 請求。P2 的 BN 可在記憶體中執行訓練模式；每批後完整還原並檢查模型參數及 buffer。

兩份權重使用相同 loss 權重：box=7.5、cls=0.5、dfl=1.5；原有 TAL 配對與 loss 公式不變。本次量測零次高階 YOLO.predict API 呼叫；直接模型前向仍會經過模型內部的 predict 方法。
